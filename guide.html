1
Make Your Decoder

Write this on paper using your 6-letter password:

Example with password "Strika":

A = S   B = t   C = r   D = i   E = k   F = a
G = b   H = c   I = d   J = e   K = f   L = g
...and continue through Z

Tip: Just match each letter to the next one in order!

2
Decode Letter by Letter

Look at each letter in the secret code and replace it using your decoder.

Example Decoding:

Secret code: x k p 2 d

Using decoder:
x → Find "x" → it says "a" → Write "S"
k → Find "k" → it says "b" → Write "t"
p → Find "p" → it says "c" → Write "r"
2 → Stays as 2 (numbers don't change)
d → Find "d" → it says "e" → Write "k"

Result: "Str2k"
3
That's It!

Just keep replacing letters using your decoder:

  • Match letters using your decoder
  • Numbers stay the same
  • Spaces stay the same
  • Do this for all the secret code letters
Time Needed: About 10-15 minutes

Super Important Tips

  • Ignore symbols like = " ( ) - they're just instructions
  • Only decode actual letters (A-Z, a-z) from the secret code
  • Keep numbers and spaces as they are - no changes needed
  • It's like a game - match letters and watch your private keys appear!

You're Done!

Once you've decoded all the letters, you'll see your private keys and seed phrase. Write them down securely and store them in a safe place!. Or you can don't decrypt it(Safer that Way)
